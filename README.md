# digdug-lite

极简《打空气》(Dig Dug)克隆：挖隧道、给敌人打气吹爆、或用落石砸死敌人。纯 Python 标准库，无第三方依赖。

## 玩法

- 你在泥土（`#`）中挖隧道，消灭所有敌人即过关。
- 两种杀敌方式：
  - **打气筒**：朝敌人发射（`f`），勾住后再按 `p` 打气，打满 4 格气敌人爆炸。停打 8 tick 会慢慢漏气。
  - **落石**：把石头下方的土挖空，石头掉下来砸死压到的敌人（500 分），但也会砸死你自己。
- 被敌人碰到或被石头砸到会丢一条命，共 3 条命。
- 敌人会在隧道里追你，在泥土里则缓慢“穿行”靠近你。

## 运行

```bash
python3 -m digdug_lite            # 交互模式（需要终端）
python3 -m digdug_lite --auto --seed 42 --moves 400   # 无头自动演示
```

## 操作（交互模式）

| 按键 | 动作 |
|------|------|
| `w` `a` `s` `d` | 上下左右移动并挖土 |
| `i` `k` `j` `l` | 只转身（瞄准上下左右） |
| `f` | 发射打气筒（沿当前朝向，最远 4 格，只能穿过隧道） |
| `p` | 给勾住的敌人打气 |
| `.` | 等待一 tick |
| `q` | 退出 |

图例：`@` 你，`P`/`F` 敌人，数字 = 敌人当前充气格数，`O` 石头（`o` = 下落中），`#` 泥土，空格 = 隧道。

## 计分

- 吹爆敌人：200 分 + 深度加成（越深的敌人分越高，每格 10 分）
- 落石砸死敌人：500 分

## 真实验证记录

- `py_compile` 通过
- 单元测试（真实执行，全部通过）：
  1. 打气筒命中 → 敌人被勾住，再打气 → 充气格 +1
  2. 打满 4 格气 → 敌人爆炸移除，得分增加
  3. 落石场景 → 石头下落砸死敌人，得 500 分
  4. 敌人走进玩家格子 → 玩家丢一条命
  5. 敌人躲在泥土后 → 打气筒被泥土挡住，勾不住
- `--auto` 无头演示：9 个种子 × 400 步全部正常结束、无崩溃（3 次胜利，其余得分 270–840；AI 是贪心演示，不保证过关）
- 敌人移速设计：隧道里每 2 tick 走 1 格（玩家一半速度），泥土里每 3 tick 穿行 1 格；玩家死后重生时敌人散开，避免重生点被守尸连续瞬死（有回归测试 T7）

## 已知局限（诚实版）

- 文本渲染、无实时键盘输入：交互是“每行一个命令”的回合制，不是实时动作游戏。
- 敌人 AI 很简单（贪心追玩家），没有原版的分阶段行为和喷火。
- 打气筒勾住后敌人完全定身（原版半充气时仍会缓慢移动）。
- 移动会立刻挣脱打气筒（原版是走开一段距离才断）。
- `--auto` 的 AI 是贪心+走位演示（会找射击角度、危险时拉开距离），9 种子中 3 次过关；石头砸敌人的高级打法它基本不会用，不保证过关。
- Python 3.10+。
